# Git Workshop 2k26

A beginner-friendly repository created as part of the **Git Workshop 2k26** to learn and practice the basic concepts and commands of Git and GitHub.

## 📌 About

This repository demonstrates the basic usage of Git, including creating a repository, tracking changes, committing files, working with branches, and pushing changes to GitHub.

## 🎯 Objectives

* Understand the basics of Git and GitHub
* Learn how to initialize and clone repositories
* Learn how to track and commit changes
* Understand branches and merging
* Learn how to push and pull changes
* Practice basic Git workflow

## 🛠️ Technologies Used

* Git
* GitHub
* HTML

## 🚀 Basic Git Commands

Some of the Git commands practiced in this workshop:

```bash
git init
git clone <repository-url>
git status
git add .
git commit -m "Commit message"
git branch
git checkout <branch-name>
git pull
git push
```

## 📚 Learning Outcomes

After completing this workshop, participants will have a basic understanding of:

* Version control
* Git repositories
* Commits
* Branches
* Remote repositories
* GitHub workflow
